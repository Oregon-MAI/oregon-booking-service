# Oregon Booking Service

Микросервис для создания и управления бронированиями ресурсов

## Быстрый старт

Запуск :

```bash
docker compose up -d
```

## Список ручек

### `BookingService`

- `CreateBooking`
- `GetBooking`
- `UserCancelBooking`
- `AdminCancelBooking`
- `ListBookingsByUser`
- `ListBookingsByResource`
